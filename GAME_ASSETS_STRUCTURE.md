## 📝 Implementation Notes

### File Naming Convention
- **SVG files** are consistently named: `Petal_0{1-6}.svg` for all countries
- **PNG files** have inconsistent numbering (some `Patel_01.png`, some `Patel_-25.png`)
- **Always use SVG files** for the game (lighter, scalable, better quality)

### Path Construction
```javascript
// Petal card path
const petalPath = `/Digital cards - Vol 1/${country.folder}/Petal_0${petalNumber}.svg`;

// Guardian path
const guardianPath = `/Digital cards - Vol 1/Guardians/${guardian.id}.svg`;

// Minion path
const minionPath = `/Digital cards - Vol 1/Minions/${minion.id}.svg`;

// Card back path
const backPath = `/Digital cards - Vol 1/Back card.svg`;
```

### Asset Loading
- Use Next.js `<Image>` component for optimized loading
- Preload critical assets (card back, first petal) for better performance
- Consider lazy loading country-specific petals until country is selected

## 🎮 Game Usage

### Deck Composition (per game)
- **6 Petal Cards** (Petal_01 through Petal_06) - Goal: Collect all 6
- **3-5 Minion Cards** (random selection from 5 available)
- **2-3 Guardian Cards** (random selection from 5 available)
- **Fill remaining slots** with duplicate petals to reach target deck size (e.g., 20 cards)

### Flower Formation
When 6 petals are collected:
- Display all 6 petal SVGs in a circular formation
- Animate them converging to center
- Show final complete flower image from `/complete-flowers/{countryFolder}.svg`
- Display flower story/description

### Complete Flower Images
All complete flower images are located in `/complete-flowers/` folder:
- **Path Pattern**: `/complete-flowers/{countryFolder}.{format}`
- **Formats**: Both `.svg` (preferred) and `.png` (fallback) available
- **Countries**: All 8 countries have complete flower images
  - `Pakistan.svg/png`, `Peru.svg/png`, `Tanzania.svg/png`, `Nicaragua.svg/png`
  - `Jamaica.svg/png`, `Espana.svg/png`, `Escocia.svg/png`, `Alemania.svg/png`
- **Function**: Use `getCompleteFlowerPath(countryFolder, format)` from `/lib/gameData.js`
